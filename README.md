# whale-brain · 小鲸鱼·粒子大脑

把 QQ 小鲸鱼的**经历**养成两颗会呼吸的粒子大脑：私聊一个自我、群聊一个自我。

## 它到底在算什么

没有"人格维度表"。脑子里每个点都是从语料里自己长出来的**概念**：

1. **概念发现**（`lib/lexicon.mjs`）—— 纯无监督新词发现：频次 + 左右邻字熵 + 内部凝固度。
   语料是它真实经历过的东西：群友说的话、它自己的内心独白、主人让它记住的事、
   它学到的黑话、它知道的冷知识、它自己上网学的词条。
2. **突触**（`lib/mind.mjs`）—— 两个概念在同一条经验里出现就连一条边（Hebb：一起放电的连在一起）。
   图上跑几轮标签传播，共现结构自己分成"脑区"，没有任何预设分区。
3. **激活与遗忘（艾宾浩斯曲线）** —— `lib/mind.mjs` 里只有一条遗忘曲线：

   ```
   R(t) = e^(−t / S)                      保持率
   S    = S0 · (1 + k · A)                记忆强度，A = 当前激活
   r    = rMin + (rMax − rMin) · (1 − R)  发散程度 = 遗忘程度
   ```

   `S0 = 2.4 天`、`k = 0.9`。刚形成的记忆 R≈1，贴在核心；完全遗忘 R≈0，飘到最外层准备消散。
   被反复想起的记忆 S 变大、R 掉得慢，所以再老也留在内圈——这就是间隔重复。
   卡片上直接显示这条记忆的 `t` 和 `S`，所以"它为什么飘在这儿"是可解释的。
4. **自我与方向** —— 共现聚出来的每个簇是一个"方向"，整簇共用一种色相（黄金角散开，相邻方向不会撞色）。
   来自它自己经验（内心独白 / 记忆 / 它自己写的词义）的概念 `selfRatio` 高，在"自我"栏里另算一份。
   所以"我是一个什么样的人"是这张图上的统计结果，不是贴上去的标签。
5. **强度（heat）** —— 激活（还在被想起）+ 自我成分（跟我有关）+ 爆发度（短时间内被反复提起）。
   越热的概念点越大、越亮、光晕越强——情绪强烈或印象深的那几个，是画面里最扎眼的光斑。
6. **三条让人更像人的机制**（都在 `ebbinghaus()` 里）：

   ```
   S  = S0 · (1 + k·A) · (1 + 0.65·q)      情绪唤醒 q 越高，固化越牢
   t' = t / (1 + min(1, 0.14·n))           重构：每想起来一次，时钟往回拨（封顶减半）
   R  = e^(−t'/S) · (1 − 0.42·c)           干扰：被更强的同类记忆压着就更难提取
   ```

   - `q` 从概念的**出处句子**算（情绪词 + 感叹号 + 连续重复字符 + 篇幅），
     不从词条本身算——概念只有两三个字，情绪藏在句子里。
   - `c` 是邻居集合的 Jaccard 相似度，且只有比自己强的邻居才算压制。
   - `n` 是累计命中次数；不封顶会让所有老记忆被拉回"新鲜"，整团云塌成一坨。

7. **遗忘是失焦，不是变暗** —— `haze = 1 - recall^0.75` 决定一个概念怎么画：
   记得清楚的是一簇紧实的小点；快忘的散成一团更大的雾，核心只剩一粒淡影，还会慢慢游移。
8. **意识流** —— 每 1.5 秒左右挑一个当前最响的概念点亮，连同它的邻居一起亮一瞬。

## 两个自我

`private:` / `group:` 把经验流天然分成两半，各自独立发现概念、独立长突触、独立遗忘。
私聊那边会长出「主动 / 撒娇 / 情感 / 孤独 / 夏天」，
群聊那边会长出「诗人 / 抽象 / 气不气 / 闭嘴 / wdf」。
同一条鱼，在两种关系里长出两个自己——这才是一个人设该有的样子。

## 自主上网学习

不是按固定主题列表搜。它挑的是**自己脑子里现在最响、又最没想明白的那个词**：

- 候选来自当前激活最高的概念（排除人名，不拿群友的名字去外面搜）
- 搜回来的句子作为一条新经验注入那个自我 → 可能长出新的概念、和原来的词连上
- 每 45 分钟一次，两个自我各自排队；面板上可以随时手动"想一个"

## 怎么打开（三种）

1. **快捷键**：`Ctrl + Shift + B` —— 不在输入框里时按一下就切到这颗脑子，再按一下切回对话
2. **桌面图标**：`小鲸鱼大脑` → `whale-brain.cmd` → `whale-brain-open.ps1`
   把 DSH 窗口叫到前台（最小化也恢复），再 `POST /whale-brain/open`，面板自己切过来
3. **侧边栏图标**：「小鲸鱼·粒子大脑」

> **不要**用浏览器直接开 `http://127.0.0.1:PORT/` —— 那是 `401 dsh web authentication required`。
> DSH 是 Electron 窗口（`dsh-app://`），令牌只在主进程里，外部浏览器进不去。
>
> 端口每次启动都会变（62870 → 64492 …），所以插件启动时把当前 origin 写进
> `$DSH_HOME/whale-brain/endpoint.json`，打开脚本读它；文件过期就直接问 DSH 进程自己在听哪个端口。

## 面板

两颗脑子并排：

- 拖拽旋转、滚轮缩放、点击粒子看它是什么（年龄 / 清晰度 / 激活 / 被想起次数）
- 右栏：概念数、突触数、平均清晰度、自我构成、刚长出来的概念、上次学了什么
- 顶部开关：自己上网学

## 数据与配置

- 经验流默认读 `D:\DSH\default-workspace\qq-bridge\state`
  （可用环境变量 `WHALE_BRAIN_STATE` 或 entry 的 `config.stateDir` 覆盖）
- 插件自己的状态写在 `$DSH_HOME/whale-brain/mind.json`（只有上网学到的词条和开关；
  概念图每次从经验流重放，不存中间态，所以不会漂）
- 宿主接口（只服务本机同源页面）：
  - `GET  /whale-brain/state` 快照（带 ETag）
  - `POST /whale-brain/learn?branch=private|group|both` 立刻想一个
  - `POST /whale-brain/auto?on=1|0` 开关自主学习
  - `GET  /whale-brain/health` 自检
